One-time setup

About 90 minutes end to end. Steps 3, 5 and 6 need the MOKIPOPS Meta, Microsoft 365 and ngrok logins; everything else is copy-paste in Terminal.

  1. Docker Desktop is installed and running

    Menu bar whale icon. Docker Desktop → Settings → General → Start Docker Desktop when you sign in, so a reboot doesn't stop the poster. The Mac is already set to never sleep (pmset -g shows sleep 0).

  2. Create the private settings file 
    cd ~/Documents/MOKIPOPS/mokipops-reel-site/n8n
cp .env.example .env
open -e .env

    Fill it in as you complete the next steps. Set N8N_ENCRYPTION_KEY to any long random string once and never change it.

  3. Meta app + permanent Page token (social posting)
    • developers.facebook.com → My Apps → Create App → use case Other → type Business → connect the MOKIPOPS business portfolio. Name: MOKIPOPS Poster.
    • Add the products Facebook Login for Business and Instagram. No configuration needed inside them.
    • App settings → Basic: privacy policy URL https://mokipops.com/policies/privacy-policy, an icon, a category → switch the top toggle from Development to Live. Posts from an app in Development mode are invisible to the public.
    • business.facebook.com → Settings → Users → System users → Add: name n8n-poster, role Admin → Add assets: MokiPops Page (full control) + @mokipops Instagram (full control).
    • On that system user → Generate new token → pick the app → expiration Never → tick pages_show_list pages_read_engagement pages_manage_posts publish_video instagram_basic instagram_content_publish business_management. Paste it into META_PAGE_TOKEN.
  4. Verify Meta and get the Instagram id 
    cd ~/Documents/MOKIPOPS/mokipops-reel-site/n8n
./verify_meta.sh

    Copy instagram_business_account.id into IG_USER_ID. Every media URL must show 200. If the Instagram block is missing, link @mokipops to the page in Meta Business Suite → Settings → Instagram and re-run.

  5. Let the mailbox send from n8n (funnel + lead alerts)
    • Microsoft 365 admin → Users → moreflavor@mokipops.com → Mail → Manage email apps → Authenticated SMTP: on.
    • If MFA is on: My Account → Security info → App password. Otherwise the mailbox password works.
    • Deliverability, do once: Microsoft Defender portal → Email authentication → DKIM → mokipops.com → Enable, then add the two selector1/selector2._domainkey CNAMEs it shows at GoDaddy. SPF already includes Outlook. Leave the HubSpot SPF include until HubSpot is fully retired.
  6. ngrok static domain (so the wholesale form can reach this Mac)

    dashboard.ngrok.com → Your Authtoken → NGROK_AUTHTOKEN. Then Domains → New domain (the free plan includes one static domain) → put it in NGROK_DOMAIN and set WEBHOOK_URL=https://<that domain>/. The tunnel only exposes /webhook/*; the editor stays local.

  7. Start n8n 
    cd ~/Documents/MOKIPOPS/mokipops-reel-site/n8n
docker compose --profile public up -d
open http://localhost:5678

    Create the owner login the first time. Without the form tunnel, plain docker compose up -d is enough.

  8. Import the three workflows and the mail credential
    • n8n → Credentials → Add → SMTP: name exactly MOKIPOPS mail (SMTP), user moreflavor@mokipops.com, password / app password, host smtp.office365.com, port 587, SSL/TLS off, STARTTLS on.
    • n8n → Workflows → ⋯ → Import from file, once each: n8n/mokipops-daily-post.json, n8n/mokipops-funnel-send.json, n8n/mokipops-lead-webhook.json.
    • Open the two email workflows, click the Send-email node and pick the credential if it isn't already selected.
  9. Test each one, then switch on
    • Posts: set DRY_RUN=true in .env → docker compose up -d → open the daily-post workflow → Execute workflow. Then DRY_RUN=false + FORCE_POST_ID=2026-10-01-facility for one real post; check facebook.com/mokipops and instagram.com/mokipops; clear FORCE_POST_ID. Toggle the workflow Active.
    • Email: FUNNEL_CAMPAIGN=A2 FUNNEL_DAILY_CAP=1, add your own address as the first buyers row in contacts.csv, execute, read it on your phone. Remove the row afterwards.
    • Form: toggle the lead-form workflow Active, then submit the form on the wholesale page. You should get the alert email and a line in contacts/leads.jsonl.
  10. Point the wholesale page at the webhook and publish

    In wholesale.html set const LEAD_ENDPOINT = "https://<NGROK_DOMAIN>/webhook/mokipops-lead"; then:

    cd ~/Documents/MOKIPOPS/mokipops-reel-site
./publish.sh

    Until that constant is set, the form falls back to opening a pre-filled email to moreflavor@mokipops.com, so no lead is lost in the meantime.

Rules that produced the numbers

  • 1/day at noon ET. Four a day tripped Facebook's ~35 posts/24 h cap (83 failures on Jul 16).
  • Video of real people (facility, kitchen, pop-ups, kids) does 5–8× the views of designed stills, so it gets 4 slots per two-month window; Hawks/award clips 3; stills 1.
  • Fresh caption every time an asset repeats; at least 7 days between repeats.
  • Holiday hooks pinned: Halloween, NBA tip-off, Thanksgiving, Black Friday, Small Business Saturday.

Keeping it fed

Extend the calendar (before the runway ends)

cd ~/Documents/MOKIPOPS/mokipops-reel-site
python3 n8n/build_queue.py 2026-12-01 2027-01-31
./publish.sh

Add a round to ROUNDS in build_queue.py if the window is longer than 63 days; put holiday hooks in OVERRIDES. Captions can also be edited directly in social-queue.json; ids must stay unique.

Add new footage

Drop a ≤90 s H.264 MP4 (9:16, at least 720 px wide) or a JPG into assets/social-library/, add it to ASSETS and CAPTIONS in build_queue.py, rebuild, publish. New clips of people making or handing out pops are the highest-value content we can add.

Re-run one slot · skip a day

Set FORCE_POST_ID=<id> in .env, execute once, clear it. To skip a day delete that row from social-queue.json and publish. Posted ids are remembered inside n8n, so a re-run never double-posts.

Sending a batch

Each click of Execute workflow on “funnel email batch” sends up to FUNNEL_DAILY_CAP messages, 30 s apart, and remembers who got which campaign. Tomorrow's click carries on with the next people.

# in n8n/.env, then: docker compose up -d
FUNNEL_CAMPAIGN=B2
FUNNEL_DAILY_CAP=40
A mailbox that has never done bulk mail needs a warm-up: 40 a day for the first week, then 60–80. Microsoft 365 hard-caps at 10,000 recipients per day, but reputation is what matters. Two or three spam complaints in a week can get the whole domain filtered, so the lead segment (no company known, never opted in) stays parked.

Every send is appended to contacts/send-log.jsonl. Replies land in the moreflavor inbox like any other email.

Sending emails by hand (with the video playing)

No n8n required. Two ways: copy a finished email into your own mail app for one-offs, or run the mailer script for a paced batch. Both use the same templates, the same log, and the same sender.

How “video in an email” actually works

Email clients don't agree on video, so every MOKIPOPS email carries three layers of the same 38-second film and each client shows the best one it can. Every layer is a link to the full player at video.html.

Reader opens it inWhat plays
Apple Mail (Mac), iPhone / iPad MailThe real video, autoplaying muted and looping inside the email. Tap for sound on the site.
Gmail (web, iOS, Android), Outlook.com / Outlook web, Yahoo, Samsung MailAnimated 5-second loop (GIF, 480 px, ~1 MB) that starts moving on open.
Outlook for Windows (desktop app)The poster frame with a ▶ caption. One click opens the film.
Images turned offThe alt text “tap to watch” plus the ▶ Watch link.

Files: assets/funnel/mokipops-wholesale-funnel.mp4 (film) · funnel-loop.gif (moving preview) · funnel-poster.jpg (still). Swap any of them and every future email picks it up; keep the GIF under ~1.5 MB.

Way 1 · One-off from your mail app

Best for replying to a lead, a warm intro, or checking how an email looks on your own phone.

  1. Click Copy on an email below. It copies the finished email as rich content, video preview included.
  2. In Apple Mail, Outlook or Gmail: New message → From: moreflavor@mokipops.com, paste into the body (⌘V).
  3. Change “Hey there” to their first name, paste the subject, send.
  4. Send yourself one first. Open it on the iPhone: the video should be moving.

Rich copy needs Chrome, Safari or Edge on this site (HTTPS). If your client pastes plain text, use the Preview link, ⌘A ⌘C there, and paste.

Way 2 · Paced batch from Terminal

Same result as the n8n batch, but you run it when you want and watch it go. Fill SMTP_PASS in n8n/.env once (step 5 of Setup).

cd ~/Documents/MOKIPOPS/mokipops-reel-site

# test it on yourself first (V = the video opener)
python3 n8n/mailer.py --campaign V --to you@example.com --name "Your Name"

# send today's batch: 40 b2b contacts, 30 s apart, skipping anyone already sent
python3 n8n/mailer.py --campaign V --segment b2b --limit 40

# add the video to any campaign, or just preview without sending
python3 n8n/mailer.py --campaign A2 --segment buyers --limit 40 --video
python3 n8n/mailer.py --campaign B2 --segment b2b --limit 5 --dry-run   # writes HTML to contacts/outbox/

# where am I?
python3 n8n/mailer.py --list

Every send is appended to contacts/send-log.jsonl, shared with the n8n batch, so neither path ever emails the same person the same campaign twice. Unsubscribe replies go in contacts/unsubscribed.txt, then python3 n8n/build_contacts.py.

Wholesale & events leads

The form on the wholesale page posts to n8n on this Mac through the ngrok tunnel.

What happens on submit

  1. Browser POSTs JSON to https://<NGROK_DOMAIN>/webhook/mokipops-lead.
  2. n8n validates it (name, real email, hidden honeypot field empty).
  3. The lead is appended to contacts/leads.jsonl.
  4. moreflavor@mokipops.com gets an alert with Reply-To set to the lead, so answering is one click.
  5. The visitor sees a thank-you in place of the form.

Checking leads

cd ~/Documents/MOKIPOPS/mokipops-reel-site
python3 -c "import json;[print(l['at'][:10],l['interest'],'·',l['name'],'·',l['email'],'·',l['company']) for l in map(json.loads,open('contacts/leads.jsonl'))]"

If ngrok or the Mac is down, the form automatically falls back to opening a pre-filled email to moreflavor@, so nothing is lost. The call list on calls.html is unchanged.

Daily & weekly

Every day (2 minutes)

  • Glance at facebook.com/mokipops — today's noon post is there.
  • If you're mid-campaign: open n8n → funnel batch → Execute workflow.
  • Answer any lead-alert emails and replies.

Every week

  • n8n → Executions: all green. Any red run names the node that failed.
  • “Days of runway” above is greater than 21; otherwise extend the queue.
  • Add any new footage from the week to the library.
  • Move unsubscribe replies into contacts/unsubscribed.txt and rebuild contacts.
